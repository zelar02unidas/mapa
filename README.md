# Mapa Zelar

Painel interativo de ativos locados por unidade (Unidas Pesados).

**Acesso:** https://mapa.zelar02-unidas.workers.dev/

## Como funciona

- O site busca os dados na planilha **`Mapa - Zelar.xlsx`** (na raiz deste repositório) a cada visita.
- Para atualizar os dados, basta substituir a planilha aqui no GitHub
  (*Add file → Upload files*). O site passa a mostrar os dados novos
  automaticamente em poucos minutos.
- Se a planilha não estiver acessível, o site exibe uma cópia embutida
  dos dados e avisa na tela.
